# Trained Models

This project includes three text generation architectures:

- Simple RNN
- GRU
- LSTM

The trained model files (*.pt) are generated locally by running the training
scripts and are intentionally not tracked by Git due to their size.

To reproduce the models:
- Run rnn_model.py
- Run gru_model.py
- Run lstm_model.py

Each script saves its trained model inside its corresponding folder.
